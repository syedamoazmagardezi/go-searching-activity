# Algorithms Implemented

# Bubble Sort

Repeatedly compares adjacent values and swaps them when they are in the wrong order.

# Selection Sort

Finds the smallest remaining value and places it in the correct position.

# Insertion Sort

Builds a sorted section by inserting each new value into its correct position.
